About the project

A zero-budget geospatial app for anime fans in the capital region.

This is a portfolio project that maps two things across Helsinki, Vantaa and Espoo: anime conventions, and the cosplay-friendly cafés, restaurants, malls and photo spots that welcome people in costume — each with pictures and a theme. It pulls open geospatial data from the City of Helsinki, renders it on a fast vector map, and ties everything together with a calendar and event list — all for €0/month.

How it works

From open data to interactive map

1

Fetch & proxy

A Next.js serverless route calls the Helsinki GIS service, sidestepping CORS and caching the GeoJSON on the edge for an hour.

2

Render on MapLibre

Venue features are injected as a GeoJSON source and styled with custom anime-themed markers, clusters and popups.

3

Connect the views

The map, calendar and event list share one dataset — click a date, jump to its pin; click a pin, see its events.

Standard GeoJSON, nothing exotic

Every convention is a single GeoJSON feature with a point geometry and a few properties. No database, no schema migrations — just a flat file that any GIS tool can read.

  • Versioned in Git alongside the code
  • Updatable by a weekly GitHub Action scraper
  • Portable to QGIS, Leaflet or Mapbox instantly
